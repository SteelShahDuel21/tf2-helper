## 🧩 About

**Team Fortress 2 Helper** is a comprehensive tool for Team Fortress 2 featuring in-game overlay, config manager, script automation, performance tweaks, HUD customization, and server browser enhancements.

Based on popular tools like **OpenTF2**, **TF2ConfigGenerator**, and **Mastercomfig**.

## ✨ Features

### 🎮 Core Features
- In-Game Overlay — display real-time stats and information
- Config Manager — easily switch between custom configs
- Script Automation — automate complex actions with scripts
- Performance Tweaks — optimize game settings for FPS
- Server Browser — enhanced server filtering and favorites

### 🎨 Customization
- HUD Customization — modify HUD elements and colors
- Crosshair Customization — create and share custom crosshairs
- Skin Changer — apply custom skins locally

### 🏋️ Training & Practice

- Demo Recording — record and analyze gameplay
- Stats Tracker — track personal performance metrics
- Map Explorer — explore maps in offline mode
